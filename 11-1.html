Web 前端 长度单位

CSS 中的绝对单位与相对单位 · 11-1 课堂实践

绝对单位（固定大小）

px 像素

最常用的单位，1px 对应屏幕上的一个物理像素点。

width: 100px; height: 60px

pt 磅

印刷单位，1pt = 1/72 英寸，常用于打印样式。

width: 72pt = 1in

in 英寸

1in = 96px = 2.54cm，源于物理尺寸。

width: 1in = 96px

cm 厘米

1cm = 37.8px，物理长度单位。

width: 2.54cm = 1in

mm 毫米

1mm = 3.78px，1cm = 10mm。

width: 25.4mm = 1in

相对单位（动态计算）

em

相对于父元素的字体大小。父元素 16px 时，1em = 16px。

width: 10em = 160px（父级 16px）

rem

相对于根元素（html）的字体大小，不受嵌套影响。

width: 8rem = 128px（根级 16px）

% 百分比

相对于父元素的对应属性值的百分比。

width: 60%（相对父容器）

vh 视口高度

相对于视口高度的百分比，1vh = 视口高度的 1%。

height: 25vh

vw 视口宽度

相对于视口宽度的百分比，1vw = 视口宽度的 1%。

width: 30vw

vmin / vmax

vmin 取视口宽高较小值的 1%，vmax 取较大值的 1%。

25vmin × 25vmin

ch 字符宽度

相对于数字 "0" 字符的宽度，常用于控制文本列宽。

width: 20ch

fr 弹性分数

CSS Grid 专用，按比例分配剩余空间。

1fr
2fr
1fr
grid-template-columns: 1fr 2fr 1fr

单位换算参考表

单位 类型 换算关系 典型用途
px 绝对 基准单位（96px = 1in） 字体大小、边框、间距
em 相对 = 父元素 font-size 内边距、外边距（相对当前文字）
rem 相对 = 根元素 font-size 统一字号、间距系统
% 相对 相对父元素的对应属性 宽度、高度、定位偏移
vh 相对 = 视口高度的 1% 全屏区块、首屏高度
vw 相对 = 视口宽度的 1% 响应式布局、流体排版
vmin 相对 = min(vw, vh) 的 1% 等比缩放元素
vmax 相对 = max(vw, vh) 的 1% 铺满视口的大元素
ch 相对 = "0" 字符宽度 文本列宽控制（最佳可读性 45-75ch）
fr 相对 Grid 剩余空间的比例分配 网格布局列宽
pt 绝对 1pt = 1/72in ≈ 1.333px 打印样式表
in 绝对 1in = 96px = 2.54cm 打印样式表
cm 绝对 1cm ≈ 37.8px 打印样式表
mm 绝对 1mm ≈ 3.78px 打印样式表
实践建议：Web 开发中最常用的是 px、em、rem、%、vh/vw。 绝对单位（pt/in/cm/mm）主要用于 @media print 打印场景。 推荐用 rem 做字号和间距系统，用 em 做组件内部相对间距，用 vh/vw 做全屏区块。
