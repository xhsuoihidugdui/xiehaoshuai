JavaScript 定时器 演示

setTimeout 单次执行 · setInterval 循环执行 · clearTimeout / clearInterval 清除
setTimeout —— 只执行一次 let id = setTimeout(fn, 2000)
等待 2000 毫秒后执行一次回调，返回定时器编号，可用 clearTimeout(id) 取消。
setInterval —— 每隔一段时间重复执行 let id = setInterval(fn, 500)
每隔 500 毫秒执行一次回调，返回定时器编号，可用 clearInterval(id) 停止。

1setTimeout 延迟执行单次

点击「2 秒后执行」后，回调在 2000ms 后只触发一次；中途可点「取消定时器」验证 clearTimeout 的效果。

const id = setTimeout(() => {
  xhsLog("2 秒到，回调只执行一次");
}, 2000);

clearTimeout(id); // 取消

2setInterval 计数器循环

每 500 毫秒计数 +1，持续运行直到调用 clearInterval 停止。

const id = setInterval(() => {
  count++;
  xhsRender(count);
}, 500);

clearInterval(id); // 停止
0 次回调 已停止

3数字时钟setInterval 实战

每秒刷新一次时间，是 setInterval 最常见的用法；点击按钮可暂停时钟。

setInterval(() => {
  clock.textContent = new Date().toLocaleTimeString();
}, 1000);

4打字机效果setTimeout 递归

用 setTimeout 反复调度自身实现逐字输出（注意：递归 setTimeout 比 setInterval 更适合变长时间间隔）。

function type(i) {
  if (i > text.length) return;
  out.textContent = text.slice(0, i);
  setTimeout(() => type(i + 1), 120);
}
点击下方按钮，文字会逐字出现。

5定时器与事件循环：谁先执行？执行顺序

点击按钮后观察日志顺序：同步代码 → Promise.then（微任务）→ setTimeout(0)（宏任务）→ setTimeout(100)。 这说明 setTimeout 的 0 毫秒并不是立刻执行，而是排到当前同步代码和微任务之后。 

console.log("1 同步代码");
setTimeout(() => console.log("3 setTimeout(0)"), 0);
Promise.resolve().then(() => console.log("2 Promise.then（微任务）"));
setTimeout(() => console.log("4 setTimeout(100)"), 100);
