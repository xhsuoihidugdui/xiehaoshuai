使用 CSS 变量实现的文字渐变效果

解浩帅
/* :root 中定义变量 */
:root {
  --xie-primary: #1e6fd9;
  --xie-accent: #f5a623;
  --xie-radius: 12px;
}

/* 使用 var() 引用变量 */
.xie-card {
  border-radius: var(--xie-radius);
  border-top-color: var(--xie-primary);
}
